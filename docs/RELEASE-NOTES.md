# Enco Lite 0.5.0-preview.3

侧栏整理为耳机概览、声音、耳机功能、设备和底部设置。概览显示设备与电量状态，聆听模式、音效和空间音频集中在声音页，均衡器作为声音页的二级页；功能开关保留独立页。配对耳机、手动型号和多设备记录集中在设备页，关于信息并入设置。沿用旧页面编号并迁移原关于页，不丢失窗口位置。

修复同一下拉框再次点击后立即重开的交互：弹层排除触发按钮所在父控件的外部点击自动关闭；再次点击由按钮直接收起。切页、打开其他列表、失焦、控件隐藏或禁用时关闭旧菜单。选项的真实协议 ID 和键盘选择保持不变。

固定聆听按钮与电量条的布局高度，避免空余空间把按钮拉成长块。17 项实际 Qt 鼠标按下/释放与导航检查通过；同一断言在旧运行包上复现失败。原有控件和窗口检查继续执行，具体证据见 VALIDATION.md。

此前 X3 控制服务超时，用户在 Windows 原生蓝牙设置断开再连接后恢复；更新包的通透、关闭、智能降噪写入和回读已复测通过，并恢复原档位，另行确认关闭 GUI 后仍保持连接。此前失败记录保留，尚未确定内部根因。

# Enco Lite 0.5.0-preview.2

修复连接提示出现时覆盖当前控制窗口路由的问题。提示保持被动显示；主窗或快捷控制仍是托盘的操作目标，避免一次单击变成再次打开快捷控制。

新增 Qt 回归断言：连接提示与快捷窗同时显示时，发送给后台的当前窗口必须仍为快捷控制。窗口动画测试改为等待真实首帧和动画完成，在明确超时内检查原生透明度，避免用冷启动后的固定 250 毫秒误判。

本轮增加最终运行包的原生快捷键消息、托盘通知、反复切换、GUI 完整退出和实际位置恢复检查。真机复测与原版对照记录独立保存在工作区 `verification/qt-retest/`，按当次结果记录，不用历史成功覆盖当前失败。

界面与安装回归通过；本轮 X3 控制服务连接仍未通过，原版对照也未完成 OPPO 会话。当前保留为已修复界面问题的预览候选，不能称为本轮真机控制全部通过。详见 VALIDATION.md。

# Enco Lite 0.5.0-preview.1

主窗口、快捷控制、连接提示全部迁移到 Qt Quick / PySide6 6.12.0。发行包不再需要 WebView2，后台继续独立维护蓝牙、托盘和快捷键。已迁移七页、主题、极速模式、窗口过渡、位置记忆、型号图片、88 条型号配置、专业竖向 EQ、设备管理及所有现有控制入口。

修复后台退出时窗口位置可能来不及保存的问题；Qt 滑块使用稳定频段模型，避免回读时重建正在拖动的控件。统一选单、快捷键录入、确认操作、充电标识和状态反馈。

Qt 版已通过 X3 降噪写入、回读与原档位恢复，关闭 GUI 后保持连接。其他型号的硬件范围仍按 README 说明；未新增未经验证的支持承诺。

发行采用系统 MSI 与便携 ZIP，附应用源码、原始 Qt/Python 许可和哈希。完整验证与内存记录见 VALIDATION.md。

# Enco Lite 0.3.0-preview.1

首个 Windows x64 安装预览版，面向 OPPO 耳机。自带运行库，支持当前用户安装、开始菜单与可选桌面入口、卸载。界面不显示演示或实测分类，型号适配边界在文档说明。

本版包括已迁移的 56 个 OPPO 型号配置、真实蓝牙控制、型号图片、圆角主窗及快捷控制、连接提示、窗口位置记忆、自定义 EQ 与能力允许的其他控制入口。真机验证仅限 OPPO Enco X3，固件 143.143.39。

修复快捷控制中充电符号在 100% 时溢出；修复托盘菜单需要再次点击才执行；缩短可见界面的状态补读间隔，后台读取不使按钮变灰；部分电量通知保留其他组件状态；处理原生非客户区边框重绘。

尚未进行发行者代码签名。当前安装验证未通过：本机应用控制拦截安装后的 Slint 组件及卸载器。安装包仅作为待签名构建产物保留，不能称为已验证可用的安装发行版；本机使用源码启动方式。安装器目标为 Windows 10 1809+ x64，本次测试在 Windows 11 上进行。Linux/macOS 的真实蓝牙和托盘未实现。查找提示音未实际播放，其他 OPPO 型号仍需真机调试。

详细证据见 `docs/VALIDATION.md`。卸载不会删除 `%APPDATA%/EncoLite/preferences.json`。
