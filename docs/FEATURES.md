# Enco Lite

OPPO / 一加耳机桌面客户端。0.5.0-preview.15 已将主窗口、快捷控制和连接提示全部迁移到 **Qt Quick / PySide6 6.12.0**，继续使用原来的 Python 协议、原生托盘和全局快捷键后台。保留绿色配色、紧凑卡片、圆角和竖向网格 EQ，运行时不使用 WebView2 或浏览器。

连接说明：曾出现 Windows 音频正常、OPPO 控制服务却超时的状态，原版对照也失败。用户在 Windows 原生蓝牙设置中断开 X3 再连接后，真实控制与回读已复测恢复；这是已验证的恢复方法，尚未确定内部根因。各次成功与失败记录分别保留，见 [VALIDATION.md](VALIDATION.md)。

## 安装与启动

安装包：`release/EncoLite-0.5.0-preview.15-win-x64.msi`；也提供同版本便携 ZIP。MSI 由 Windows Installer 安装和卸载，便携包解压后运行“启动 Enco Lite.cmd”。包内自带官方 CPython 和所需 Qt 动态库，无需另装 Python、Qt 或 WebView2。

源码目录使用工作区根目录的“启动 Enco Lite.cmd”或“快捷控制.cmd”。先在 Windows 蓝牙设置中配对 OPPO 或一加耳机。当前实际运行和硬件测试环境为 Windows 11 x64；Linux/macOS 尚未实现真实蓝牙与托盘，跨平台 Qt 界面不等于已完成跨平台硬件支持。

单文件 Inno setup.exe 在这台电脑上曾被应用控制拦截，当前使用 MSI 和便携包。不购买或导入证书，也不修改系统安全策略；本机通过不保证其他机器的策略判定。

## 开机自启动

在“设置 → 启动与性能 → 开机自启动”开启，默认关闭。在当前用户的 Windows“启动”文件夹创建原生快捷方式，使用当前目录的官方 pythonw.exe 和绝对脚本路径，带 --tray-only；登录后先运行托盘与连接后台，主窗按需打开，连接提示仍按原设置显示。不另外常驻 Qt 或创建任务计划。

状态从实际快捷方式读取，写入后回读；权限、文件缺失或超过 启动路径长度限制时显示失败。便携版移动目录后需在新位置重新开关自启动。安装版升级/重装保留注册，卸载时只清理指向自身目录的项，不移除另一份便携版的注册。启动时间受 Windows 调度与系统启动应用设置管理。

## 窗口与外观

设置按外观、快捷控制、启动与性能、快捷键、关于分组。置顶、闲置收起与连接提示集中在快捷控制；极速模式与快速唤出集中在启动与性能。闲置时长仅在开启自动收起后显示。

- 单击托盘图标立即打开或收起快捷控制，双击恢复主窗口；右键菜单一次选择直接执行。
- 主窗口默认 864×640，可调整大小、最小化和最大化。快捷控制默认 352×374。Qt 自动处理 DPI，位置、正常尺寸、最大化和页面保存为独立 Qt 偏好，并可迁移旧版窗口位置。
- 点关闭时不会被延迟首帧或悬停重新打开；关闭动画若中断，会在 350ms 内完成窗口释放。
- 快捷控制默认置顶，“设置 → 快捷控制 → 始终置顶”可随时关闭；切换立即应用到已打开的窗口，选择会持久保存，不改变主窗口层级。
- 快捷控制默认持续显示；可在“设置 → 快捷控制”打开“闲置后自动收起”，按最后一次操作计时，5–3600 秒可自定，默认时长 30 秒。关闭开关会保留填写的时长。鼠标、键盘、滚轮及触摸会重新计时；展开选单时暂停，按住鼠标或耳机操作尚未完成时暂缓；电量等状态刷新不延长时间。收起只关闭快捷窗，保留托盘与蓝牙，遵守快速唤出的进程保留选择。
- 连接提示仍独立计时；连接提示默认显示 5 秒，悬停暂停，移开后 3 秒收起，不主动抢焦点。
- 主窗与快捷窗切换时，等待目标首帧呈现后关闭旧窗。窗口通过轻微上浮、缩放与淡入展开，关闭时反向收拢淡出；主窗约 320/220ms，快捷控制与连接提示约 280/200ms。连续显示请求保留当前动画进度，关闭中重开从当前位置衔接；窗口实际坐标和大小不随动画变化。页面、按钮、菜单和开关保留短暂过渡。
- 配对列表结合蓝牙耳机类型与 OPPO / 一加耳机名称筛选，同品牌手机、电脑、键盘、音箱等不再混入；设备类型缺失时只对明确耳机型号或系列后备识别。
- 配色可选八种预设色，也可用饱和度/亮度面板、色相条或颜色值自选；主题色还可跟随 Windows 强调色。深浅外观独立设置，主窗、快捷控制、连接提示共用配色，自动调整文字对比度。
- 支持跟随系统 / 浅色 / 深色。“极速模式”关闭额外动画；系统减少动画时也跳过过渡。没有常驻的装饰动画。
- 默认关闭最后一个窗口后整个 Qt 图形进程退出，托盘和蓝牙连接继续工作。蓝牙后台不导入 PySide6，不运行 Qt、WebView2、Slint、Tk 或 .NET。
- 设置中的“快速唤出”默认关闭。开启后，关闭窗口仍会销毁视图，但保留独立 Qt 界面进程，以减少再次打开的等待；相应增加后台内存。关闭该开关即可恢复退出图形进程。初次启动仍需加载运行库。与关闭动画的“极速模式”相互独立。
- 所有选单使用同一主题，支持键盘操作；较长型号列表可搜索。降噪时显示强度，通透时按型号能力显示子模式，关闭时收起该行。
- 侧栏为耳机概览、声音、耳机功能、设备及底部设置。概览只显示设备状态；声音内含聆听/音效与均衡器二级页，功能页保留功能开关，设备页集中配对耳机选择、手动型号和多设备管理，关于信息并入设置。
- 同一下拉框再次点击会收起，打开另一个列表或切页会关闭旧列表；控件隐藏、禁用或窗口失焦时也会收起。实时电量变化不打断正在使用的菜单。

## 快捷键

应用设置中可启用、录入、清除快捷键，后台通过 Windows RegisterHotKey / WM_HOTKEY 接收，不使用全局键盘钩子。

| 操作 | 默认快捷键 |
| --- | --- |
| 降噪 / 通透切换 | Ctrl + Alt + N |
| 打开快捷控制 | Ctrl + Alt + Q |
| 打开主窗口、关闭聆听模式、下一音效 | 默认未设置，可自行录入 |

允许 Ctrl 或 Alt 搭配字母、数字、导航键或 F1–F24，F12 和系统保留组合除外，可叠加 Shift。冲突时保留旧绑定并显示原因。录入期间暂停本应用注册，保存、取消、失焦、切换窗口、图形退出及 45 秒租约到期后恢复。

## 耳机功能

沿用原项目 OPPO / 一加共用协议与 88 条配置（56 条 OPPO、32 条一加），按产品 ID、实际索引和能力开放控件：

| 类别 | 功能 |
| --- | --- |
| 连接与状态 | 配对设备发现、能力协商、取消连接、自动重连、手动型号、电量与充电、佩戴、固件和编解码器 |
| 聆听模式 | 降噪、通透、人声通透、关闭及型号支持的强度和自适应模式 |
| 声音 | 原厂音效、自定义 EQ 列表、实际频段竖向推子与共享 dB 网格、保存并使用、试听修改、删除确认 |
| 功能 | 佩戴检测、双设备、游戏、人声/听力增强、长续航、低音及对应型号的空间音效 |
| 扩展 | 空间类型、游戏音效类型、多设备列表及能力允许的连接/断开/优先级/取消配对、查找提示音 |

Qt 只渲染界面，通过有界 UTF-8 JSON 管道调用原有串行后台。写入后回读确认，拒绝和超时会显示实际状态，不伪造成功。可见窗口补读与后台事件更新继续复用现有逻辑。

**真实硬件验证限 OPPO Enco X3，固件 143.143.39。** Qt 迁移后已验证真实连接、界面状态、降噪写入与回读、恢复原档位和关闭 GUI 后保持连接。其他型号为上游配置与协议移植及模拟验证，尚未实机验证；应用内不以此区分标签。一加保留 32 条白名单、历史 ID、服务 UUID、稀疏音效索引和型号能力限制。没有 SPP 的 Bullets Wireless Z2 不能因出现在目录中就视为可控制。

上游没有实现的固件升级、完整听力校准及触控映射不属于已迁移范围。X3 多设备管理只显示设备声明支持的操作。使用查找提示音前需取下耳机并确认；取消配对、删除音效也需要在界面确认。

## 图片与设置

按产品 ID 显示 35 个型号的官方图片（31 个 OPPO、4 个一加）；缺图使用中性图标，不借用其他型号图片，也不显示固定颜色文字。原始资源来源保存在 `ui/assets/models/manifest.json`。用户覆盖图可放在 `%LOCALAPPDATA%/EncoLite/images/<产品ID>/product.png`。

偏好在 `%APPDATA%/EncoLite/preferences.json`，卸载保留。窗口、主题、快捷键等合并保存；退出后台时也等待 Qt 回传位置。协议记录只保留最近 32 条，不持续写日志。

## 玻璃效果

“设置 → 外观 → 玻璃效果”控制主窗口、快捷控制和连接提示的原生 Acrylic 背景，默认开启。深浅色与主题配合，卡片和菜单保留较实的底色保证可读性。极速模式会立即关闭玻璃效果并禁用开关；退出极速模式后恢复原来的选择。Windows 关闭透明效果、开启高对比度或不支持原生材质时自动使用实色背景。

模糊由 Windows 合成器处理，没有额外图形运行库或持续截图。拖动和调整窗口大小期间暂时使用实色背景，结束后恢复，避免 Acrylic 在部分系统上的拖动停顿。没有窗口时不保留材质事件监听。
