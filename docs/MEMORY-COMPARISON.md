# 原版与当前客户端实测

## 完整 Qt 客户端：0.5.0-preview.1

2026-10-24，实际连接 X3，官方 Python 3.13.17 + Qt Quick / PySide6 6.12.0。主窗、切换后的快捷窗、关闭所有窗口后的托盘依次各预热 25 秒，再以 0.5 秒间隔取完整进程树 15 次均值。没有使用界面样例、强制 GC 或工作集裁剪。

| 状态 | 独占驻留内存（USS，MiB） | 私有提交（MiB） | 工作集合计（MiB） | 进程数 |
| --- | ---: | ---: | ---: | ---: |
| Qt 完整客户端主窗 | 139.98 | 180.64 | 247.18 | 2 |
| Qt 快捷控制（由主窗切入） | 136.30 | 180.69 | 244.43 | 2 |
| Qt 客户端仅托盘、X3 保持连接 | 14.59 | 15.39 | 41.12 | 1 |
| 同机此前实测原版主窗 | 186.56 | 206.82 | 292.03 | 1 |
| 同机此前实测 WebView2 客户端主窗 | 169.02 | 235.41 | 465.31 | 8 |

这次 Qt 主窗 USS 比此前原版样本低约 25%，比 WebView2 样本低约 17%；私有提交分别低约 13% 和 23%。这些是同机分时测量，不能视为所有机器或长期运行的固定降幅。Qt 快捷窗沿用已打开主窗的同一引擎，包含缓存成本，不代表冷启动快捷窗。仅托盘状态已无图形子进程；不与未经测量的原版托盘比较。

脚本 `tools/measure_qt_client.py`；完整原始样本与真实连接记录 `verification/qt-memory/report.json`。USS 不计共享驻留页，私有提交不等于物理 RAM，工作集求和会重复计入共享页，均不计独立显存。测试未做长期泄漏、反向顺序或启动耗时比较。切换窗口的对象销毁另由 `verify_qt_windows.py` 验证，不以一次稳态内存推断长期无泄漏。

## 迁移前：WebView2 与原版

2026-10-24，在同一台 Windows 电脑顺序启动文件夹内原版与当前源码客户端。两者均真实连接 OPPO Enco X3，未使用模拟状态。各状态启动后等待 25 秒，间隔 0.5 秒采集 15 次完整进程树，表中为均值，单位 MiB。

| 状态 | 独占驻留内存（USS） | 私有提交量 | 工作集合计 | 进程数 |
| --- | ---: | ---: | ---: | ---: |
| 原版 2.0.1-r6 主窗口 | 186.56 | 206.82 | 292.03 | 1 |
| 当前客户端主窗口 | 169.02 | 235.41 | 465.31 | 8 |
| 当前客户端仅托盘 | 13.40 | 15.74 | 27.64 | 1 |

USS 是进程独占的驻留物理页面，不含共享页面；不能代表应用及所有共享资源的完整物理成本。私有提交量包含可能尚未驻留或已换出的页面，不等同于物理内存。工作集进程求和会重复计算共享页面，不能把 465 MiB 全部解释为当前客户端独占 RAM。表内未计入独立显存成本。

本轮主窗口独占驻留均值当前约低 9.4%，私有提交均值约高 13.8%，不能据此宣称显著节省内存。当前主窗口 USS 样本为 152.71–180.88 MiB，原版为 186.30–186.77 MiB。前一轮仅测工作集与私有提交，原版分别为 311.67 / 227.38 MiB，当前分别为 464.86 / 233.35 MiB，说明短时启动及运行时状态也会影响结果。

原版为现存 Windows x64 NativeAOT Release，已包含该项目 r6 内存修复，源码提交 b656112b661cb3857af66920d9783e57e59d1c7e；并非未经改动的上游公开版本。EXE SHA-256：c722074074d0b559fdafdc864b57407accbee7ea01b4968818c2fe55e1f454cb。

当前为 Python 3.13.17 + Win32 + WebView2 的更新后源码入口，不是旧的已打包预览版；主窗口统计包含后台、图形宿主与全部 WebView2 子进程。后台与图形分别启动，测试中不同时占用耳机连接。采样程序未调用工作集裁剪或强制 GC；原版自身的既有资源管理策略保持原样。

computer-use 工具因 sandboxCwd 的 WSL URI 错误无法初始化，本轮使用只读窗口元数据、原版新日志和当前客户端退出前状态确认窗口及真实连接。原版主窗口采样后结束此次测试创建的进程；没有自动化操作原版托盘菜单，故未取得原版托盘/快捷窗数据，不能据此判断后台相对原版的下降比例。测试结束已恢复当前客户端正常主窗口。未做长期泄漏、反向启动顺序、启动时间或动画帧率比较。

完整样本：`verification/memory-comparison.json`；前一轮：`verification/memory-comparison-pass1.json`。重测脚本 `verification/benchmark-original-memory.py` 会依次切换程序与连接，运行前应结束其他原版实例；不是只读监视器。连接观察包装器只在退出时记录状态，不改变协议或渲染流程。
