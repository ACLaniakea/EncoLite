# 0.5.0-preview.6：托盘唤出延迟

- 旧版为了区分单击/双击，用原生计时器固定等待 350ms；另外默认关闭最后一个窗口后退出 Qt，因此下次点击要冷启图形进程。正式入口三次复测（当前系统文件缓存，非磁盘冷启动）首帧为 1192.5/1228.9/1241.3ms，完全不透明为 1384.1/1413.2/1414.6ms；该数据尚未加托盘等待。记录 `verification/qt-startup/direct-before.json`。
- 首批插桩包装曾出现 2–4s 创建延迟、淡入停在 0.01 或主窗创建超时；对照未插桩正式入口未重现，所以这些包装结果明确排除，不据此认定生产动画或 Python 3.13 有缺陷。软件渲染与 Python 3.12 仅作诊断对照，没有替换发布运行库或渲染后端。
- 托盘改为直接分发版本 4 的 NIN_SELECT/NIN_KEYSELECT，不再等待 350ms；该模式忽略重复的旧式 WM_LBUTTONUP，待处理选择事件合并一次。双击仍进入主窗，后续鼠标释放/选择不会反向打开快捷窗。右键菜单逻辑保留。
- 主窗口主体按需创建，打开快捷窗不再构建隐藏的侧栏与主窗容器。最后窗口关闭时仍默认退出完整图形进程，保持原有低内存选择。
- 新增默认关闭的“快速唤出”：开启后保留独立 Qt 界面进程、销毁关闭的窗口，并通过 idle 消息把后台可见性清为 false。再次打开重用引擎，关闭选项时也能释放已空闲的 GUI；托盘、蓝牙和快捷键继续运行。该选项增加后台内存，界面直接标明代价，不自动修改用户偏好。初次启动仍需加载运行库。

## 0.2.1 窗口和操作回归

`verification/desktop-interactions.json` 的 11 项检查通过：窗口没有原生标题栏/客户区装饰边；DWM 接受关闭描边设置；主窗与快捷窗切换保留页面、位置与尺寸；再次激活不取消最大化；连接提示保持主窗前台；刷新不重复提示；悬停暂停计时；提示进入共享快捷控制；显式快捷入口不反向关闭；显式关闭释放快捷窗口；禁用提醒及超时释放。

原生窗口可能在 Slint show() 返回后才就绪。新实现有界等待实际句柄，再完成定位、边框和工具窗属性，防止首次设置丢失；不再每次激活都强制“还原”窗口，也不反复清除系统为缩放维护的扩展样式。圆角区域和 UI 遮罩在最大化时同步变为方角。

`verification/window-persistence.json` 用独立进程验证普通与最大化两组重启场景，覆盖主窗位置/页面、最大化后还原的位置与快捷窗位置恢复；主题及连接提示设置不会覆盖位置。另有边界测试覆盖负坐标显示器、无效配置、显示器断开后的可见区域调整。保存时机为窗口收起或应用退出。

取消连接覆盖“工作线程尚未开始”和“握手成功但 UI 尚未完成”两种竞态，防止用户已取消却又连上。点击当前已选降噪/音效不重复写设备。后续调试已移除快捷窗失焦轮询；手动快捷控制只在明确关闭或切回主窗口时释放。

`verification/connection-notice-live.json` 的 4 项 X3 只读实机检查通过：真实握手与电量生成提示；刷新不重复；断开释放旧提示；重新连接产生一次新提示。没有修改耳机设置。

弹窗文字已放大：连接提示型号 17px、电量/操作 14px；快捷窗型号 16px、电量 18px、主要操作 14px。连接提示调整为 360×180，已渲染检查文字无挤压。

连接提示默认 5 秒收起，悬停停止计时，移开后 3 秒收起；其窗口不占额外任务栏按钮，点击后进入手动快捷窗。设置里可以关闭。参考上游 `UI/Toast/ToastManager.cs` 的连接提示与生命周期逻辑。

## 后续源码调试：快捷控制停留与主窗激活

手动打开的快捷控制保持显示，失焦和等待不会关闭它。关闭按钮、托盘单击切换、打开主窗口继续正常收起快捷控制。只有连接提示沿用原有的 5 秒计时。移除了快捷窗的 200ms 失焦轮询，也不再用 test_mode 隐藏这段生产逻辑。

主窗口激活等实际 HWND 就绪；恢复保存位置后再激活，首次句柄缺失或激活失败时短暂有界重试。激活后读取实际前台窗口确认，再收起快捷窗。查找窗口只选可见句柄，防止旧的同名隐藏组件仍存活时定位错误。重复启动的本应用进程向既有客户端传递前台权限，最小化窗口恢复，已最大化窗口保留状态。没有将主窗口设置为永久置顶。

`tools/verify_window_lifetime.py` 使用真实原生窗口和生产生命周期策略，检查初始句柄延迟时前台激活、手动快捷窗失焦后超过 5 秒仍显示、显式关闭、快捷入口恢复主窗、最小化恢复和保留最大化。6 项检查通过，结果见 `verification/window-lifetime.json`。最小化测试保留本应用前台权限来模拟用户主动操作，没有放开系统前台权限限制。现有窗口交互、位置记忆和源码冒烟另行复查。这批修改用于当前源码调试版，之前生成的未签名安装包尚未包含。
