# 签名与安装验证状态

没有购买证书，也没有修改系统安全设置。用户希望继续寻找保留防护的免费办法。

原项目 EXE 同样未签名。智能应用控制可依据文件信誉或受信任签名放行，不能概括为所有安装版都必须买证书。

原版 PyInstaller 安装构建被拦截的组件为 Slint PYD，卸载器也曾被拒绝。源码入口依赖已恢复，但最新重新加载 Slint 的检查同样遭到应用控制拒绝，不能继续宣称源码当前可用。后来制作了 Slint 静态编入主 EXE、CPython 官方签名运行库和系统 MSI 卸载的候选版；它曾通过安装后的完整界面检查，但重复安装后 EXE 本身也被拦截，所以仍未达到可用发行标准。

后续优先路线为微软商店 MSIX 私有内测：个人注册免费，商店认证后由微软免费签名；普通 MSI/EXE 商店提交不享受这种自动签名。SignPath Foundation 可申请，但有开源项目和构建范围审核，不能承诺获批。详见 [不购买证书的分发路线](FREE-DISTRIBUTION.md)。

没有提交任何应用、资料或账号申请，没有购买、创建或导入签名证书。自签名证书不等同于智能应用控制认可的公开受信任发行者。普通双击启动的稳定性必须在最终分发渠道和本机安全策略下再次验证。
