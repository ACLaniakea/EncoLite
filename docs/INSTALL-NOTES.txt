Enco Lite 0.5.0-preview.18

先在 Windows 蓝牙设置中配对 OPPO 或一加耳机。
包内自带官方 Python 和 Qt Quick 运行库，无需安装 WebView2。
双击 MSI 显示安装向导，可选择安装目录、创建桌面快捷方式，并在完成时打开应用。
默认安装到当前用户目录，不添加开机自启。
升级会沿用已有安装位置；再次打开同版本 MSI 可修复或卸载。

单击托盘打开快捷控制，双击打开主窗口，右键打开菜单。
默认关闭最后一个窗口后释放界面进程并保留耳机连接；退出请使用托盘菜单。
快捷控制可在设置启用闲置自动收起，时间支持 5–3600 秒；默认关闭，开启初始为 30 秒。
快捷控制默认置顶，可在设置中的“快捷控制置顶”切换并记忆选择。
“快速唤出”默认关闭；开启后用更多后台内存缩短再次打开的等待。
主窗与快捷窗记住位置；应用设置可调整外观、动画、连接提示和快捷键。

设置中的主题色可自选或跟随 Windows；深浅外观单独选择。
已配对列表只保留可识别的 OPPO / 一加耳机，不列同品牌手机。

真实硬件验证限 OPPO Enco X3。其他型号的验证范围详见 README。
卸载保留 %APPDATA%\EncoLite 下的个人设置。
开源许可、第三方说明和应用源码随安装包提供。

设置按外观、快捷控制、性能、快捷键、关于分组；自动收起及闲置时长位于快捷控制组。

窗口显示改为上浮、缩放与淡入，关闭时反向收拢淡出；连续开关可以平滑反转。极速模式与系统减少动画仍会跳过全部窗口过渡。

“设置 → 启动与性能”新增开机自启动，默认关闭。开启后登录 Windows 时先在托盘运行；便携版移动目录后需重新开关。卸载只清理自身启动路径，重装/升级保留注册。底部圆角和描边统一绘制，并修正分数缩放下的对齐。

玻璃效果需要 Windows 11 22H2 或更新版本，使用系统 Acrylic、圆角和描边，拖动时保留。旧系统使用实色界面。极速模式关闭模糊和动画，退出后恢复玻璃偏好。
